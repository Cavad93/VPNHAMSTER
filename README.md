# VPNHAMSTER 🐹

**Безопасный TCP туннель для обхода блокировок**

Собственная реализация VPN туннеля с использованием TUN/TAP интерфейсов. Подключение выглядит как обычное TCP соединение к удаленному компьютеру, что делает блокировку практически невозможной.

## 🎯 Особенности

- **Полная незаметность**: Выглядит как обычное TCP соединение к IP адресу
- **Сильное шифрование**: ChaCha20-Poly1305 (современный и быстрый алгоритм)
- **TUN/TAP интерфейс**: Весь системный трафик проходит через туннель
- **Простая настройка**: Минимальная конфигурация
- **Кросс-платформенность**: Mac (клиент) + Windows (сервер)

## 🏗️ Архитектура

```
[Mac Client] --TCP--> [Windows Server (Астана)] ---> Internet
    (TUN)        (Шифрованный трафик)      (Открытый доступ)
```

### Как это работает:

1. **На Mac**: Создается виртуальный сетевой интерфейс (TUN)
2. **Весь трафик** перенаправляется через этот интерфейс
3. **Шифрование**: Трафик шифруется ChaCha20-Poly1305
4. **TCP туннель**: Шифрованные пакеты отправляются на сервер через обычный TCP
5. **На сервере**: Пакеты расшифровываются и отправляются в интернет
6. **Ответы** идут обратно тем же путем

## 📋 Требования

### Mac (Клиент)
- macOS 10.14+
- Python 3.8+
- Права root (sudo)

### Windows (Сервер в Астане)
- Windows 10/11 или Windows Server 2016+
- Python 3.8+
- Права администратора

## 🚀 Быстрый старт

### 1. Установка на сервере (Windows в Астане)

```powershell
# Клонировать репозиторий
git clone https://github.com/yourusername/VPNHAMSTER.git
cd VPNHAMSTER

# Запустить PowerShell от имени администратора
.\scripts\setup_windows.ps1

# Сгенерировать ключ шифрования
python scripts\generate_key.py

# Сохраните полученный ключ!
```

### 2. Настройка сервера

Откройте порт в Windows Firewall:

```powershell
# PowerShell от администратора
New-NetFirewallRule -DisplayName "VPN Tunnel" -Direction Inbound -LocalPort 8888 -Protocol TCP -Action Allow
```

Запустите сервер:

```powershell
python server\server.py --key YOUR_HEX_KEY_HERE
```

### 3. Установка на клиенте (Mac)

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/VPNHAMSTER.git
cd VPNHAMSTER

# Установка зависимостей
sudo ./scripts/setup_mac.sh
```

### 4. Подключение с Mac

```bash
# Используйте тот же ключ, что и на сервере
sudo python3 client/client.py --server YOUR_SERVER_IP --key YOUR_HEX_KEY
```

**Готово!** Весь трафик теперь идет через ваш сервер в Астане.

## 📖 Подробная документация

### Генерация ключа шифрования

```bash
python3 scripts/generate_key.py
```

Это создаст 256-битный ключ. **Важно**: Используйте один и тот же ключ на клиенте и сервере.

### Параметры сервера

```bash
python server/server.py \
  --host 0.0.0.0 \          # Принимать со всех интерфейсов
  --port 8888 \              # TCP порт
  --key YOUR_KEY \           # Ключ шифрования
  --tun-ip 10.8.0.1          # IP туннельного интерфейса
```

### Параметры клиента

```bash
sudo python3 client/client.py \
  --server 1.2.3.4 \         # IP сервера в Астане
  --port 8888 \              # TCP порт сервера
  --key YOUR_KEY \           # Ключ шифрования (тот же что и на сервере)
  --tun-ip 10.8.0.2 \        # Локальный IP туннеля
  --gateway 10.8.0.1         # IP шлюза (сервера)
```

## 🔒 Безопасность

### Шифрование

- **Алгоритм**: ChaCha20-Poly1305
- **Длина ключа**: 256 бит
- **Аутентификация**: Poly1305 MAC
- **Защита от replay**: Случайный nonce для каждого пакета

### Рекомендации

1. **Генерируйте уникальный ключ** для каждой установки
2. **Не передавайте ключ** по незащищенным каналам
3. **Храните ключ безопасно** (не в публичных репозиториях)
4. **Используйте сильные пароли** для доступа к серверу

## 🛠️ Устранение неполадок

### "Permission denied" при создании TUN интерфейса

```bash
# Убедитесь что используете sudo
sudo python3 client/client.py --server ... --key ...
```

### Не удается подключиться к серверу

1. Проверьте, что сервер запущен
2. Проверьте firewall на сервере
3. Проверьте IP адрес сервера
4. Проверьте, что порт открыт: `telnet SERVER_IP 8888`

### Туннель создается, но нет интернета

1. Проверьте настройки маршрутизации на сервере
2. Убедитесь, что IP forwarding включен на Windows
3. Проверьте логи сервера

### pytun не устанавливается

На Mac может потребоваться:

```bash
# Установить Xcode Command Line Tools
xcode-select --install

# Затем установить pytun
pip3 install python-pytun
```

## 🔧 Технические детали

### Протокол

Каждое сообщение имеет структуру:

```
[Длина (4 байта)] [Зашифрованные данные]

Расшифрованные данные:
[Тип (1 байт)] [Длина полезной нагрузки (4 байта)] [Данные]
```

### Типы сообщений

- `HELLO (1)`: Начало соединения
- `HELLO_ACK (2)`: Подтверждение соединения
- `DATA (3)`: IP пакет
- `KEEPALIVE (4)`: Поддержание соединения
- `DISCONNECT (5)`: Закрытие соединения

### Шифрование

Каждый пакет:
1. Генерируется случайный nonce (12 байт)
2. Данные шифруются ChaCha20-Poly1305
3. Формат: `[nonce (12 байт)] [ciphertext] [tag (16 байт)]`

## ⚠️ Ограничения

- Работает только на macOS (клиент) и Windows (сервер)
- Не поддерживает множественные одновременные подключения от одного клиента
